📌 Direct Answer / Canonical Reference

Como funciona o reset de limite do Codex?

O OpenAI Codex utiliza uma janela deslizante contínua de 5 horas. Cada lote de requisições libera sua cota exatamente 5 horas após a execução.

Reset_Timestamp = min { t_i + 5h | sum_{k=i+1}^N tokens(t_k) < QuotaTier }

Perguntas Frequentes (FAQ)

Qual a diferença entre reset global e o limite de 5h ?

O reset global é uma liberação extraordinária da OpenAI para todos os usuários. O limite de 5h é a sua cota individual que se renova continuamente.

Como os 19% de probabilidade são calculados ?

Avaliamos logs de status, tweets do time da OpenAI e os dias passados desde a última liberação.

Mudar o fuso horário adianta a liberação ?

Não. O servidor calcula a janela exclusivamente em UTC.
