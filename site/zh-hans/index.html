OpenAI Codex 限流何时恢复？机制详解

OpenAI Codex 采用严格的 5 小时连续滑动时间窗口机制。消耗的 Token 并不会在午夜 00:00 UTC 统一刷新，而是在每次发问后精确经过 5 小时（300分钟）逐步分批解冻。

Reset_Timestamp = min { t_i + 5h | sum_{k=i+1}^N tokens(t_k) < QuotaTier }

常见问题解答 (FAQ)

公共大重置与个人 5 小时限流有何区别？

公共大重置是 OpenAI 官方在特殊节点手动为全体付费用户刷新额度或发放福利；个人 5 小时限流则是常态机制，按您自己的请求时间戳向后滑动 5 小时逐步解锁。

19% 的公共重置概率是如何推演出来的？

由我们的信号台结合官方服务状态、管理层推文语义分析以及距离上次放水的天数（当前 34 天）综合评分计算。

切换电脑时区能否提前解封？

不能。所有时间均以 OpenAI 服务器 UTC 时间为准。建议在等待期间无缝切换到 Cursor 或 Claude Code 继续写代码。
